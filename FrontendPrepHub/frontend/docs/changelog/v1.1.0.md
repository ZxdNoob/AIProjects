## ✨ 新增功能

### 1. 在线 IDE 全面升级

本次版本对在线 IDE 进行了全面重构和功能增强，打造业界顶级的前端代码编辑器体验。

#### 1.1 多文件管理系统
- **文件树组件**：完整的文件/文件夹结构展示
- **文件操作**：支持创建、删除、重命名文件和文件夹
- **文件类型识别**：根据扩展名显示不同颜色的图标
  - JavaScript: 黄色
  - TypeScript: 蓝色
  - HTML: 橙色
  - CSS: 粉色
  - JSON: 黄绿色
- **可折叠侧边栏**：一键隐藏/显示文件树

#### 1.2 多标签页编辑器
- **多文件同时编辑**：支持打开多个文件标签
- **未保存提示**：圆点标记表示有未保存的修改
- **右键菜单**：关闭、关闭其他、关闭全部
- **语言指示器**：每个标签显示文件语言颜色

#### 1.3 代码编辑器增强
- **Monaco Editor**：VS Code 同款编辑器引擎
- **多主题支持**：
  - VS Code Dark（默认）
  - VS Code Light
  - High Contrast
- **代码格式化**：快捷键 `Shift+Alt+F`
- **智能补全**：自动提示、语法高亮
- **代码折叠**：自动识别代码块
- **括号配对**：彩色括号匹配
- **字体连字**：支持 Fira Code 等编程字体连字特性

#### 1.4 可拖拽布局
- **分割面板**：水平/垂直方向拖拽调整大小
- **多种布局模式**：
  - 水平分割（编辑器左 + 预览右）
  - 垂直分割（编辑器上 + 预览下）
  - 仅预览
  - 仅编辑器

#### 1.5 实时预览增强
- **自动刷新**：代码修改即时预览
- **响应式设计**：桌面/平板/手机视图切换
- **设备模拟**：iPhone、iPad、MacBook 等预设
- **设备边框**：可开关的设备外框效果
- **缩放控制**：25%-200% 缩放预览
- **屏幕旋转**：横屏/竖屏切换
- **新窗口打开**：独立窗口预览
- **复制代码**：一键复制完整代码

#### 1.6 终端/控制台
- **实时日志**：捕获 `console.log/info/warn/error`
- **消息过滤**：按类型筛选日志
- **时间戳**：每条日志显示时间
- **导出日志**：下载为文本文件
- **可最小化**：节省屏幕空间

#### 1.7 项目模板系统
提供 5 个精美预设模板：
1. **空白项目**：从零开始
2. **现代着陆页**：产品展示页面，包含导航、Hero、特性展示
3. **数据仪表盘**：现代化数据可视化界面
4. **CSS 动画库**：精美动画效果合集
5. **Todo 应用**：完整待办事项应用

#### 1.8 云端存储
- **保存到云端**：登录后保存项目
- **加载项目**：从云端加载已保存项目
- **项目搜索**：快速查找项目
- **删除管理**：删除不需要的项目

#### 1.9 导出功能
- **导出 HTML**：下载完整的 HTML 文件
- **代码复制**：复制完整代码到剪贴板

#### 1.10 快捷键支持
| 快捷键 | 功能 |
|--------|------|
| `Ctrl/⌘ + S` | 保存项目 |
| `Ctrl/⌘ + Enter` | 运行代码 |
| `Shift + Alt + F` | 格式化代码 |

## 🐛 Bug 修复

### 1. 修复文件树下拉菜单定位问题
- **问题描述**：文件操作的下拉菜单显示在屏幕最右侧
- **修复方案**：使用 `fixed` 定位并动态计算菜单位置

### 2. 修复文件树下拉菜单层级问题
- **问题描述**：下拉菜单被编辑器遮挡
- **修复方案**：设置 `zIndex: 9999` 确保菜单显示在最上层

### 3. 修复 Vite 开发服务器启动失败
- **问题描述**：`EADDRNOTAVAIL` 错误，地址 198.18.0.23:5173 不可用
- **原因分析**：VPN/代理影响了 localhost DNS 解析
- **修复方案**：在 `vite.config.ts` 中明确指定 `host: '127.0.0.1'`
