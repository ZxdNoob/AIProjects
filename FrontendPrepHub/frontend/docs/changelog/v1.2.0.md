## ✨ 新增功能

### 1. Mock 模式支持

支持在无后端环境下预览和体验完整功能，适用于 GitHub Pages 部署和演示。

#### 1.1 Mock 数据服务
- **完整的模拟数据**：提供用户、知识点、编程题、算法题等模拟数据
- **真实的数据结构**：Mock 数据与真实 API 响应结构完全一致
- **丰富的示例内容**：
  - 4 个知识点（JavaScript、React、CSS、TypeScript）
  - 3 道编程题（防抖函数、Promise.all、深拷贝）
  - 3 道算法题（冒泡排序、快速排序、二分查找）
  - 学习进度数据

#### 1.2 自动 Fallback 机制
- **智能检测**：自动检测后端服务可用性
- **无缝切换**：后端不可用时自动切换到 Mock 模式
- **环境感知**：GitHub Pages 环境自动启用 Mock 模式
- **手动控制**：支持通过 `localStorage` 手动切换模式

#### 1.3 API 代理层
- **统一接口**：新增 `services/index.ts` 作为 API 统一入口
- **透明代理**：对业务代码透明，无需修改调用方式
- **错误处理**：网络错误时自动降级到 Mock 数据

### 2. GitHub Pages 部署支持

#### 2.1 Vite 配置优化
- **动态 base 路径**：支持通过环境变量配置部署路径
- **子目录部署**：正确处理 `/AIProjects/FrontendPrepHub/` 路径

#### 2.2 路由配置优化
- **BrowserRouter basename**：正确配置子目录路由
- **SPA 支持**：404.html 支持客户端路由刷新

### 3. Render 后端部署配置

- **Blueprint 配置**：支持一键部署到 Render
- **环境变量**：预配置 MongoDB 和 JWT 相关变量
- **健康检查**：配置 `/api/health` 端点检查
