# v1.0.1 版本说明

**发布日期：** 2025-12-28

## 🐛 Bug 修复

### Vite 开发服务器启动失败

- **问题**：运行 `npm run dev` 时报错 `EADDRNOTAVAIL: address not available`
- **原因**：系统网络配置导致 Vite 绑定到不可用的 IP 地址
- **修复**：在 `vite.config.ts` 中显式设置 `host: '127.0.0.1'`

### TypeScript 模块解析错误

- **问题**：`Cannot find module 'path'` 和 `__dirname is not defined`
- **原因**：缺少 `@types/node` 类型声明，ESM 模块不支持 CommonJS 变量
- **修复**：
  - 安装 `@types/node` 依赖
  - 更新 `tsconfig.node.json` 配置
  - 使用 `import.meta.url` 构造 `__dirname`

## 🔧 配置变更

### vite.config.ts

```typescript
// 新增 ESM 兼容导入
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));

// 新增服务器配置
server: {
  host: '127.0.0.1',
}
```

### tsconfig.node.json

```json
{
  "compilerOptions": {
    "types": ["@types/node"]  // 新增
  }
}
```
