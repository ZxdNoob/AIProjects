## 📝 版本说明格式

每个版本说明文档应包含以下内容：

1. **版本信息**
   - 版本号
   - 发布日期
   - 更新类型（新功能/修复/优化/破坏性变更）

2. **新增功能**
   - 功能描述
   - 使用说明
   - 相关文件

3. **Bug 修复**
   - 修复的问题
   - 影响范围
   - 修复方案

4. **性能优化**
   - 优化内容
   - 优化效果
   - 技术细节

5. **破坏性变更**
   - 变更内容
   - 迁移指南
   - 兼容性说明

6. **依赖更新**
   - 新增依赖
   - 升级依赖
   - 移除依赖
