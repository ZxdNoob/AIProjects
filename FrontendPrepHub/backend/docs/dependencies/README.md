# 后端依赖包变更说明

本目录记录后端项目依赖包的变更情况。

## 📋 变更记录

| 日期 | 变更类型 | 依赖包 | 说明 | 文档 |
|------|---------|--------|------|------|
| - | - | - | - | - |

## 📝 变更类型

- **新增**：添加新的依赖包
- **升级**：升级现有依赖包版本
- **降级**：降低依赖包版本
- **移除**：移除不再使用的依赖包
- **替换**：用其他依赖包替换现有依赖包

## 📄 文档格式

每个依赖变更文档应包含以下内容：

1. **变更信息**
   - 变更日期
   - 变更类型
   - 变更原因

2. **依赖包信息**
   - 包名称
   - 版本号（变更前 → 变更后）
   - 包用途

3. **影响分析**
   - 对项目的影响
   - 需要修改的代码
   - API 兼容性说明
   - 数据库兼容性说明

4. **使用说明**
   - 新依赖的使用方法
   - 配置变更
   - 注意事项

5. **安全更新**
   - 安全漏洞修复
   - 安全建议
