## 📝 版本说明格式

每个版本说明文档应包含以下内容：

1. **版本信息**
   - 版本号
   - 发布日期
   - 更新类型（新功能/修复/优化/破坏性变更）

2. **新增功能**
   - 功能描述
   - API 接口说明
   - 数据库变更

3. **Bug 修复**
   - 修复的问题
   - 影响范围
   - 修复方案

4. **性能优化**
   - 优化内容
   - 优化效果
   - 技术细节

5. **API 变更**
   - 新增接口
   - 修改接口
   - 废弃接口
   - 破坏性变更

6. **数据库变更**
   - 模型变更
   - 迁移脚本
   - 数据兼容性

7. **依赖更新**
   - 新增依赖
   - 升级依赖
   - 移除依赖
