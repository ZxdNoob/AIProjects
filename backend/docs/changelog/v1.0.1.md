# v1.0.1 版本说明

**发布日期：** 2025-12-28

## 🐛 Bug 修复

### MongoDB 连接问题

- **问题**：连接 MongoDB 时报错 `ECONNREFUSED ::1:27017`
- **原因**：`localhost` 被解析为 IPv6 地址，而 MongoDB 只监听 IPv4
- **修复**：将 `.env` 中的 `localhost` 改为 `127.0.0.1`

### TypeScript 编译错误

- **问题**：编译时报错 `The operand of a 'delete' operator must be optional`
- **原因**：TypeScript 严格模式下 `delete` 操作符只能用于可选属性
- **修复**：将 `delete ret.password` 改为 `ret.password = undefined`
